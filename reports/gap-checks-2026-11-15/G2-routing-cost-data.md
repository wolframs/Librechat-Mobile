**Concrete price correctness gap:** M/MarketPrice.kt:82 uses `effective?.value(lane) ?: best.value(lane)`. The sidecar deliberately supplies an existing effective object with null prices when routing/trust is unknown or no eligible seller exists (`markets.py:310–315,382–407`). Mobile substitutes the whole-market best while its heading still says this key's price (`MarketPriceSheet.kt:86–89`). Web preserves unavailable prices and explains routing/trust uncertainty (`MarketPricePopover.tsx:331–355,437–460`). Source-proven; not reproduced on a device. The fallback also affects unknown effective cache lanes. A phone user needs this corrected when comparing prices.

**Accounting boundary:** saved per-turn `metadata.usage.cost` uses the server rate table, not the gateway's settled export. Transactions separately carry `rateDetail`, `routedVia` and gateway request IDs; dashboard reconciliation distinguishes nominal/settled spending. Mobile reads neither those transaction nor settlement records. It therefore already has per-turn costs while lacking actual gateway charges/confidence. Smallest useful phone addition: label gateway rate-table costs as estimates. Settled per-turn charges require an owned-message API join, not direct database access or allocation from global totals. Useful for an unexpectedly expensive turn; full settlement investigation is a desk tool. Evidence: usage.ts:263–346; transaction schema; D/cost-and-pricing:177–257,304–327,769–794. D/follow-ups' audit warns of refused/stopped-turn booking and direct-endpoint 1h write rates; I did not independently re-audit fixes or charges.

**Access/scope:** nginx permits signed-in users to read `/cost/markets` and `/cost/markets/endpoints`; other cost/routing routes require admin (`nginx/default.conf:97–135`). Sidebar links also check ADMIN. Cost collection is whole-stack accounting, not personal spend for the current app user. Existing summary routes suit an admin phone; regular-user spend needs a scoped backend contract. The external dashboard link may need a browser login; opening a URL does not transfer the app session.

## Verdict
**real gap**: native credit/spend awareness and routing preferences are missing; unknown eligible prices are displayed incorrectly. Much market data and per-turn usage/cost totals already exist. Affinity already runs server-side. Full accounting tables belong in the browser.
